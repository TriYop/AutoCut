# AutoCut

An tool for extracticg sequences from video files

## Goal

Pour éditer des fichiers vidéos de webinaires, je veux identifier les moments pendant lesquels le présentateur hésiteou bafouille automatiquement. Les régions identifiées seront marquées pour être coupées ou éliminées.
Cette tâche prenant beaucoup de temps, je voudrais l'automatiser.
